디자인 템플릿 관리

수업 페이지(vibe-coding)의 디자인을 고르고, 선택한 연도에 적용합니다. 기능과 내용은 그대로이고 모양과 움직임만 바뀝니다.

1. GitHub 연결

토큰은 어떻게 만드나요?
  1. GitHub에 로그인한 뒤 오른쪽 위 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Expiration(만료)은 30~90일, Only select repositories에서 proj 만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만든 뒤 한 번만 보이는 토큰(github_pat_ 로 시작)을 위 칸에 붙여넣기

3. 테마 선택

카드마다 들어 있는 작은 화면이 그 테마의 느낌입니다. 아래 5~7번에서 고른 옵션은 어떤 테마에서든 함께 적용됩니다.

4. 레이아웃 · 카드 형태와 마우스 호버

카드 형태 (명예의 전당·예시 작품)

마우스 호버 효과

호버 카드 위에 마우스를 올리면 효과가 재생됩니다. 호버는 PC에서만 보이며, 폰에서는 터치로 대신합니다.

5. 타이포그래피

테마와 별개로 글꼴 조합만 바꿉니다. 제목은 영문 글꼴 + 한글 Pretendard 굵게, 본문은 Pretendard, 번호·태그는 모노스페이스입니다.

6. 모션 · 인터랙션

타이틀 등장 (하나 선택)

추가 효과 (여러 개 선택 가능)

학생 기기의 '동작 줄이기(모션 감소)' 설정이 켜져 있으면 모션은 자동으로 꺼집니다. 모션을 전부 끄고 싶으면 위 선택을 모두 해제하세요.

7. 미리보기와 적용

위에서 고른 설정이 아래 실제 페이지에 바로 반영됩니다. 미리보기는 저장되지 않습니다.

미리보기의 작품 썸네일은 소리 없이 불러옵니다. 적용 후 학생 화면에는 1~2분 뒤 반영됩니다.
