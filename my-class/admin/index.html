디자인 템플릿 관리

수업 페이지(vibe-coding)의 디자인을 고르고, 선택한 연도에 적용합니다. 기능과 내용은 그대로이고 모양만 바뀝니다.

1. GitHub 연결

토큰은 어떻게 만드나요?
  1. GitHub에 로그인한 뒤 오른쪽 위 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Expiration(만료)은 30~90일, Only select repositories에서 proj 만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만든 뒤 한 번만 보이는 토큰(github_pat_ 로 시작)을 위 칸에 붙여넣기

4. 미리보기와 적용

미리보기의 작품 썸네일은 소리 없이 불러옵니다. 적용 후 학생 화면에는 1~2분 뒤 반영됩니다.
